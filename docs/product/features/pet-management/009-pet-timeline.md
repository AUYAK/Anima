# Feature: Pet Timeline
Status: Ready

## Goal
One scrollable feed that shows the pet's life — past and future — anchored on "Today": upcoming events above, history below.

## User Stories
- As a pet owner, I want to scroll through my pet's history so that I can relive our story in one place.
- As a pet owner, I want to see upcoming events right above today so that I know what's next without opening a calendar.
- As a pet owner, I want the app to add milestone entries automatically (birthday, "one year together") so that special dates are part of the story even if I forget to log them.

---

## Core principle

**Gallery is the archive. Timeline is the story.**

Only deliberate entries appear on the timeline: moments, events, and milestones. Photos uploaded directly to the gallery never appear here — no bulk-upload noise, no context-free photos. Data flows one way: a moment always lands in the gallery; a gallery photo never lands on the timeline.

---

## Entry types

| Type | Source | Zone | Visual |
|---|---|---|---|
| Moment | Feature 012 — photo + tag + caption | Past | Rich photo card |
| Planned event | Feature 003 — vaccine, grooming, vet visit | Future | Outline card, no fill, countdown |
| Completed event | Feature 003 — event marked done | Past | Compact row, green checkmark |
| Milestone | Auto-generated by the app | Past | Accent card with icon, no photo |

**Milestones** (auto-generated, user never creates them):
- "Joined Anima" — the pet's `created_at` date; always the first (oldest) entry on the timeline
- Birthday — yearly, from date of birth (only dates after the pet joined the app)
- Anniversary together — yearly, from `created_at` ("1 year together")
- Title unlocked — when the user earns a title (feature 013)

## Screen anatomy

```
┌─────────────────────────────┐
│ ←  Grom's Timeline          │
│ [All] [Moments] [Events] [Milestones]
├─────────────────────────────┤
│  ┌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┐   │
│  ╎ 🎂 Birthday · in 12 days ╎ │  <- FUTURE: outline cards,
│  └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘   │     countdown, max 3,
│  ┌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┐   │     nearest closest to Today
│  ╎ 💉 Vaccine · in 3 days   ╎ │
│  └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘   │
│ ────────── Today ────────── │
│  ┌──────────────────────┐   │
│  │ [photo]              │   │  <- PAST: moments as
│  │ 🐾 Walk · "First snow!" │  │     photo cards
│  └──────────────────────┘   │
│  ✓ 🏥 Vet visit · Jul 2     │  <- completed events: rows
│  ── June 2026 ──            │  <- month separators
│  ⭐ 1 year together          │  <- milestones: accent cards
│  ...                        │
│  🏠 Joined Anima · Jun 2025 │  <- always the last entry
└─────────────────────────────┘
```

**Future zone**
- Max 3 upcoming events, sorted so the nearest is closest to the "Today" line
- Outline cards (no fill, no photo) with icon + title + countdown ("in 3 days")
- If no upcoming events: zone is hidden entirely — no placeholder
- Capped at 3 so the "Today" line is visible without scrolling when the screen opens

**Today line**
- Horizontal divider labeled "Today"; the screen opens with it visible

**Past zone**
- Reverse chronological (newest first), scrolls down into history
- Month separators between months ("June 2026")
- Moments: photo card — photo, tag icon + tag name, caption, time
- Completed events: compact row — green checkmark + icon + title + date
- Milestones: accent card — icon + text, visually distinct (these are rare and precious)

**Day stacking**
- 2+ moments on the same calendar day collapse into one stacked card with a "+N" badge
- Tap expands the stack inline

**Filters**
- Chips under the header: All | Moments | Events | Milestones
- "Events" covers both planned and completed
- Filter applies to both zones

---

## Interactions
- Tap a moment → full-screen photo view (same viewer as gallery)
- Tap a stacked card → expand inline
- Planned/completed events and milestones: not tappable for now (event details come with 003)

## Acceptance Criteria

### Structure
- [ ] Screen opens with the "Today" line visible without scrolling
- [ ] Future zone shows max 3 upcoming events, nearest closest to Today
- [ ] Future zone hidden when there are no upcoming events
- [ ] Past zone sorted newest first with month separators
- [ ] "Joined Anima" milestone is always the oldest entry

### Entries
- [ ] Moments render as photo cards with tag + caption + time
- [ ] Completed events render as compact rows with checkmark
- [ ] Milestones render as accent cards, visually distinct from moments
- [ ] 2+ moments on one day collapse into a stack with "+N"; tap expands
- [ ] Gallery-only photos do NOT appear on the timeline

### Milestones
- [ ] Birthday milestone generated yearly from date of birth (skipped if DOB not set)
- [ ] Anniversary milestone generated yearly from pet created_at
- [ ] Milestones dated before the pet joined the app are not generated

### Filters
- [ ] All four filter chips work and apply to both zones
- [ ] Empty filter result shows "No entries of this type yet"

### Interactions
- [ ] Tap moment opens full-screen photo view

## Screens

## Navigation
- PetProfileScreen Timeline "See all" → TimelineScreen
- TimelineScreen back → PetProfileScreen
- Moment tap → full-screen photo viewer → back to TimelineScreen

## Empty / Error States
- Empty (no entries at all): illustration + "Grom's story starts here" + "Add a moment" button → opens Add Moment flow (012)
- Empty filter: "No entries of this type yet"
- Load error: "Couldn't load the timeline" + Retry button

---

## Phasing

**Phase 1 (now, after 012):** past zone with moments + auto-milestones. Future zone and completed events wait for 003; until then the future zone is hidden and the Events filter chip is hidden.

**Phase 2 (with 003):** future zone with planned events; completed events in the past; Events filter chip appears. Event completion flow ("mark done + attach photo") is defined in the 003 spec, not here.

**Phase 3 (with 013):** "Title unlocked" milestones.

## Impact on existing specs
- Replaces the "biography tab" concept from 001-pet-profile.md (tabs removed by 011 anyway)
- Feature 011: timeline strip on the pet profile shows a mix — 1 nearest upcoming event + 2 most recent past entries (3 most recent past if nothing upcoming)
- Feature 003 (when specced) must include: `planned / completed` event state and a completion flow

## Dependencies
- Feature 012 (Moments) — main content source; build after 012
- Feature 003 (Event Calendar) — future zone + completed events (Phase 2)
- Feature 013 (Achievements) — title milestones (Phase 3)

## Out of Scope
- Gallery photos on the timeline (gallery = archive, timeline = story)
- "Convert a gallery photo into a moment" bridge (future iteration)
- Editing or deleting entries from the timeline (moments editing is out of scope in 012 too)
- Event completion flow (belongs to 003)
- Comments, reactions, social feed
- Extended future planning view (full calendar lives in 003)
